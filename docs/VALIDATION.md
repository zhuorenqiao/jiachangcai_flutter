本次新增覆盖：

- 左右滑动切换 5 个标签页，底部导航高亮与页面索引双向同步。
- 鼠标拖拽同样可以滑动（默认 `ScrollBehavior` 只接受触摸类设备，已为分页器单独放开）。
- 页内垂直拖动不会误触发标签切换。
- 首页分类磁贴跳转到点餐页并滚动到该分类。
- 跳转动画进行中滑走该页不会抛异常。
- 滑动打断点击切页动画时，底部导航高亮仍跟随分页器实际停留的页面。

顺带修复两个既有/新引入缺陷：

1. 点餐页菜品区原为惰性 `ListView`，滚动到视口外的分类不会构建，导致点击首页靠后的分类时 `jump()` 因取不到该分类的 `GlobalKey` 而静默不滚动。菜品总数很小，改为一次性构建全部分类的 `SingleChildScrollView + Column`。此缺陷与滑动改动无关，是被新增的「分类跳转」断言暴露出来的。
2. 引入滑动后，若在点击切页动画进行中滑动，页面会停在被滑到的页面，而底部高亮仍停在原目标页。已在动画结束时按分页器实际页码回填 `tab`。

验证方式：新增的滑动断言均做过变异测试（改坏实现后测试确实失败），例如移除鼠标拖动支持、移除分页器同步、移除分类跳转、把菜品区改回惰性列表、移除动画结束时的页码回填，均在 Widget 测试或真实浏览器中复现失败。
